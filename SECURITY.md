# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue or pull request for security vulnerabilities.**

To report a security issue in any `Oxbow-Education` repository:

1. **GitHub Private Vulnerability Reporting (preferred):** Navigate to the **Security** tab of the affected repository and click **Report a vulnerability** to open a private advisory with the maintainers.
2. **Direct contact:** Reach out directly to WhereWeGo engineering (`reza@wherewego.org` / the WhereWeGo engineering channel) with:
   - Affected repository and environment (staging or production URL, if applicable)
   - Steps to reproduce or proof-of-concept details
   - Potential impact and any relevant logs or request identifiers (without including sensitive user data or credentials)

We will acknowledge receipt, assess impact, coordinate a fix on a private branch if needed, and rotate any affected credentials before disclosure.
